# Unified significant-only layout v2

`plot_ame_unified_significant_v2.py` places significant Strength motifs first and
significant Weaken motifs immediately below them in one horizontal bar chart.
Non-significant representative families are omitted. Both sections share the same
x-axis, and motifs remain q-ranked within each state. The main title is shortened
to `AME motif enrichment`; method details are kept in the footnote.
