## 后处理参数和统计口径

MACS2 pooled、q0.05、nolambda/broad 脚本使用 `-f BAMPE`、`--keep-dup all`，treatment 指向 `target.markdup.sorted.bam`，IgG 指向 `target.dedup.sorted.bam`。这些是实际文件来源与命令参数；duplicate flag 是否被工具读入、是否已在上游过滤，仍应核实，不能只凭文件名断言最终计数策略。

历史命令保留了 `--nomodel --shift -75 --extsize 150`。MACS2 2.2.7.1 文档说明 BAMPE 使用实际双端片段，非零 shift 不适用于该模式；现有日志又显示命令成功并采用观测片段长度。整理未改写该历史参数。正式复跑前应核实该版本实际处理行为，并采用符合 BAMPE 说明的参数记录。这组参数不能被当成已经做过新的“nomodel 灵敏度试验”。

`p5q2` 是 narrowPeak 第 8 列≥5 且第 9 列≥2，即 -log10(p)≥5 且 -log10(q)≥2。它是旧统计表的附加过滤口径。q0.05 分析没有重新套 q0.01 的 p5q2 作为候选定义，否则会把放宽结果重新滤严。

`ppois` 是逐碱基 -log10(P) 信号。区域均值、最大值以及高分碱基比例是描述性摘要，不是整个区域的 P/Q 值。pooled 重新 call peak 与两重复分别 call peak 后取交集是两种不同结果。

## 方法出处

- [nf-core/cutandrun 3.2.2 使用说明](https://nf-co.re/cutandrun/3.2.2/docs/usage/) 和 [参数页](https://nf-co.re/cutandrun/3.2.2/parameters)：样本表、对照、normalisation 和 consensus 的软件定义。
- [MACS2 2.2.7.1](https://pypi.org/project/MACS2/2.2.7.1/)：BAMPE、gsize、q、broad、nolambda、duplicate 和 bedGraph 输出定义。
- [SEACR 官方仓库](https://github.com/FredHutch/SEACR)：背景、norm 与 stringent 的定义。
- [BEDTools intersect](https://bedtools.readthedocs.io/en/latest/content/tools/intersect.html)：正长度相交、支持原峰和 overlap fraction。
- [pyBigWig 原始区间和统计说明](https://github.com/deeptools/pyBigWig#compute-summary-information-on-a-range)：缺失碱基及汇总分母。
- [deepTools computeMatrix](https://deeptools.readthedocs.io/en/3.5.2/content/tools/computeMatrix.html)：TSS coverage profile 的生成。

依据链接帮助解释参数；本归档的已运行参数仍应由项目命令、MACS2 `_peaks.xls`、Nextflow resolved params 和 trace 相互核对。
