# 现有信号定量审计（2026-10-09）

## 结论

这次文件完成了区域信号汇总，但不能作为Tag/IgG富集的最终判定。原因是旧脚本的CPM均值未把同一有效染色体上的未记录碱基统一补零；候选区间又是整段基因±2 kb，而非TSS。应先修正定量，不必重跑比对或call peak。

已有严格重复共同peak计数仍然有效：119-Tag/MACS2 22个，其中7个与119-Pol2共同peak重叠；SEACR 876个，其中845个重叠。两者都属于共占位线索，不能证明蛋白互作；比例不能跨caller直接比较，也没有随机背景检验。

137与rRNA：AEMK02000489.1:43231–45101值得重点复核。现有数值显示137两个重复的CPM条件均值均高于119，但MACS2共同peak只触及该rRNA起始边界31 bp，不能说整个rDNA单位富集。另一条SEACR共同peak几乎覆盖的5.8S rRNA（AEMK02000695.1:10195–10348）在旧均值下137两个重复均低于IgG，应避免将该重叠直接当成验证成功。

此前tRNA无重叠不能用来否定Pol III：输入tRNA注释只有17个MT条目，没有核tRNA。输入23个rRNA条目中MT两条也未出现在这次21行的定量表。

全体13,826个119-Pol II/MACS2共同区间上，119-Tag pooled ppois区域均值的中位数为0.484，Pol II为8.994；上述7个共占位候选对应中位数分别为2.744和27.588。这支持优先逐位点复核，不能推广为119在所有Pol II位点普遍富集。区域是按Pol II峰选择的，这个比较本身存在选择偏差，不能直接给两种蛋白比较显著性。

SEACR的845/876是以Tag区间计数，798是以相交Pol II区间计数；一对多重叠可导致二者不同。这798个Pol II区间上的119-Tag ppois均值中位数为0.339，故SEACR高重叠率不等于已通过MACS2 IgG-relative信号验证。

## 下一步

1. 对已有14条bigWig做原始区间精确积分：CPM在有效染色体内的未记录区间补零；缺失染色体标NA，不猜测chr前缀。
2. 对12个候选基因分开输出基因体、gene-level TSS±2 kb、TSS±500 bp和±2 kb的100 bp分箱。注意gene-level TSS不是所有转录本TSS。
3. 原有Tag共同peak和119-Pol2共同peak也做同口径定量；复核rRNA邻域分箱，区分内部与边缘信号。
4. 跨状态CPM比值只是相对信号比较，没有spike-in，不能推断绝对全局占位变化。Inflammation需预定义基因集、匹配背景与正式富集检验，现有12个PPI候选不足以证明。
5. 重复支持规则不变；无需通过放松MACS2阈值寻找预期结果。

## 方法依据

- [deepTools 3.5.1 的实际汇总代码](https://deeptools.readthedocs.io/en/3.5.1/_modules/deeptools/getScorePerBigWigBin.html)：调用bwh.stats，未设置exact=True。

- 本地nf-core/cutandrun 3.2.2 conf/modules.config 的CPM bamCoverage配置含--skipNAs，生成稀疏轨道。
